DSH Workspace — Support

Last updated: 2026-10-01

DSH Workspace is an iPhone and iPad client for DeepSeek Harness. Run DeepSeek Harness on your computer, then connect the App to it.

Connect your computer

  1. Install DeepSeek Harness 0.2.0 or newer on your computer and run dsh web.
  2. Install the LAN gateway plugin: dsh plugin --profile web add @riceawa/dsh-lan-gateway.
  3. In a DeepSeek Harness conversation on that computer, run lan_gateway set-password and then lan_gateway enable. Use a password of at least 8 characters. lan_gateway status shows the gateway status and port.
  4. In the App, enter the computer's local network address and gateway port (usually 3081), such as http://192.168.1.20:3081, followed by the gateway password you set.

Your phone and computer need to be on the same local network. Use the computer's address, not 127.0.0.1 or the local port used by dsh web. Access from another network requires your own reachable address and HTTPS setup.

The gateway rejects plain HTTP by default. If you use HTTP on a trusted local network, set allowInsecurePlaintext: true under the existing dsh-lan-gateway configuration in ~/.dsh/profiles/web/cordis.patch.yml. Other devices on that network may see passwords and cookies sent over HTTP. Use HTTPS across networks.

Browse the computer's folders in the App

DeepSeek Harness may open a native computer dialog when choosing a folder locally. A phone cannot operate that dialog. DeepSeek Harness already includes plugins for browsing folders inside the page. Add this configuration to the end of ~/.dsh/profiles/web/cordis.patch.yml on the computer:

- id: directory-picker
  disabled: true
- insert:
    - id: directory-picker-browse
      name: '@deepseek-ai/dsh-host-directory-picker-browse'
    - id: ui-directory-picker-browse
      name: '@deepseek-ai/dsh-client-ui-directory-picker-browse'

Save the file, then reopen the App's new chat screen. Refresh any open DeepSeek Harness web page. “Add workspace” on the web will now list the computer's folders inside the page too.

Troubleshooting

  • Cannot reach the server: check that the computer is awake, the gateway is enabled, and the address and port are correct. On a phone, 127.0.0.1 refers to the phone itself.
  • Wrong password: enter the gateway password set with lan_gateway set-password.
  • Connected, but no sessions appear: check that DeepSeek Harness on the computer is version 0.2.0 or newer.
  • Cannot load folders for a new chat: check that the configuration above is in the web profile. On the computer, click “Add workspace” in the web workspace to check that folders appear inside the page.
  • Voice input does not work: check the App's Microphone and Speech Recognition permissions in iOS Settings.
