DSH Workspace — Support

Last updated: 2026-09-29

DSH Workspace is an iPhone and iPad client for a DeepSeek Harness (DSH) server that you run or that someone runs for you. The App ships without a server: to use it you need an address to connect to.

What you need

  • A reachable DSH web workspace (an https:// address, or a http:// address on your own network).
  • The sign-in link that dsh web prints, which contains the token. Paste the whole link into the App's setup screen; the token is used to sign in and is not saved as part of the address.

Connecting

  1. On the setup screen, paste the sign-in link and continue. The App opens the workspace's own sign-in page to establish the session.
  2. Once signed in, the App reads your sessions from that server and shows them natively. The web workspace stays available from Settings.

If something does not work

  • “Could not reach DSH.” — check the address and that the server is running. Over the internet the address must be HTTPS; plain HTTP is only allowed on a local network.
  • Signed in, but no sessions. — the account has nothing yet, or the session expired: open the web workspace once from Settings and sign in again.
  • Browsing folders is empty or refused. — remote folder browsing comes from the DSH web profile: enable the dsh-host-directory-picker-browse and dsh-client-ui-directory-picker-browse plugins on the server.
  • Voice input does nothing. — the App needs Microphone and Speech Recognition permission (iOS Settings › Privacy & Security). If the keyboard is up, dismiss it first.
  • A long answer or log looks cut off. — open the execution details from the “…” menu in the conversation.

What the App does not do

It does not host a server, does not create accounts, and does not send anything anywhere except the server you configured. See the Privacy Policy.

Contact

Anything not covered here — write to info@miramiao.com. Please mention the App version (Settings › About) and, if it is a connection problem, which server address you used (never send your token).
