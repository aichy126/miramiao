DSH 工作台 — 支持

最后更新：2026-10-01

DSH 工作台是 DeepSeek Harness 的 iPhone 和 iPad 客户端。你需要在自己的电脑上运行 DeepSeek Harness，再让 App 连接到它。

连接电脑

  1. 在电脑上安装 DeepSeek Harness 0.2.0 或更新版本，运行 dsh web。
  2. 安装局域网网关插件：dsh plugin --profile web add @riceawa/dsh-lan-gateway。
  3. 在电脑的 DeepSeek Harness 对话中依次执行 lan_gateway set-password 和 lan_gateway enable。密码至少 8 位；lan_gateway status 可查看网关状态和端口。
  4. 在 App 中填写电脑的局域网地址和网关端口（通常是 3081），例如 http://192.168.1.20:3081，再输入刚设置的网关密码。

手机和电脑需要在同一个局域网。请填写电脑的地址，而不是 127.0.0.1，也不要填写 dsh web 使用的本机端口。跨网络访问需要自行配置可访问的地址和 HTTPS。

网关默认拒绝明文 HTTP。如果你只在可信的局域网内使用 HTTP，需要在 ~/.dsh/profiles/web/cordis.patch.yml 中已有的 dsh-lan-gateway 配置下设置 allowInsecurePlaintext: true。HTTP 上的密码和 cookie 可被同一网络中的设备看到；跨网络使用 HTTPS。

让 App 浏览电脑上的文件夹

DeepSeek Harness 的自动目录选择器在本机可能打开电脑的系统窗口，手机无法操作。DeepSeek Harness 已包含页面内目录浏览插件；在电脑的 ~/.dsh/profiles/web/cordis.patch.yml 末尾加入以下配置，切换目录选择方式：

- id: directory-picker
  disabled: true
- insert:
    - id: directory-picker-browse
      name: '@deepseek-ai/dsh-host-directory-picker-browse'
    - id: ui-directory-picker-browse
      name: '@deepseek-ai/dsh-client-ui-directory-picker-browse'

保存后重新打开 App 的新建对话页；已打开的 DeepSeek Harness 网页也请刷新。网页端的「添加工作区」此时同样会在页面内列出电脑上的文件夹。

遇到问题

  • 连不上服务器：确认电脑没有休眠、网关已启用，并检查地址和端口。127.0.0.1 在手机上指手机自身。
  • 密码错误：输入 lan_gateway set-password 设置的网关密码。
  • 已连接但会话列表为空：检查电脑上的 DeepSeek Harness 是否为 0.2.0 或更新版本。
  • 新建对话无法加载文件夹：检查上面的配置是否写入 web profile；在电脑的网页工作台点击「添加工作区」验证是否出现页面内目录列表。
  • 语音输入无法使用：在 iOS 设置中检查本应用的麦克风和语音识别权限。
