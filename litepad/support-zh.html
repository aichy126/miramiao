常见问题

怎么在任何地方把 Litepad 叫出来？

按呼出快捷键（默认 Control-Option-空格）。窗口会出现在你当前所在的桌面、其他应用的前面；再按一次会隐藏 Litepad。快捷键可以在「设置 › 通用」里修改。

快捷键用的是哪一套？

多光标、行编辑、选择默认与 Sublime Text 的键位一致。每条命令都能在「设置 › 快捷键」里改，完整列表在「帮助」里。

跳到定义提示「按名字查找」

Go 文件会优先使用你 Mac 上装好的 gopls（go install golang.org/x/tools/gopls@latest）。第一次使用时，Litepad 会请你在访达面板里允许一个小的辅助脚本，用来运行这个工具。没有 gopls 时，会在打开的文件夹里按名字查找定义和引用。

格式化没有反应

JavaScript、TypeScript、CSS、HTML、JSON、YAML 和 Markdown 用内置的格式化工具。其他语言用你 Mac 上装好的工具（比如 gofmt、black），在「设置 › 代码」里可以看到找到了哪些。

关掉了程序坞图标，菜单去哪了？

没有打开窗口时，Litepad 只在菜单栏里；只要有窗口打开，程序坞图标和菜单就会回来。

Litepad Pro 包含什么？

Git 面板：比较没提交的改动、整个分支、或从任意一次提交以来的改动，逐处跳转，提交与历史；当前行末尾显示最后一次修改；跳到定义、查找引用、悬停信息；格式化与保存时自动格式化；全部 12 套皮肤与毛玻璃效果。同时去掉免费版的限制：每个窗口 5 个标签、保留最近 10 条临时笔记、收藏 3 个项目。一次买断，不是订阅。

以前的临时笔记不见了

免费版保留最近 10 条临时笔记，更早的会移到废纸篓，不会直接删除，打开废纸篓就能拿回来。正在打开的笔记不会被移走。升级到 Pro 后没有这个限制。

行尾那行灰字是什么？

在 Git 仓库里，光标所在行的末尾会显示这一行最后一次修改的作者、时间和提交说明；还没提交的行显示「没提交的改动」。不需要的话，在「设置 › 编辑 › Git」里关掉。

打字时弹出的提示词能关吗？

可以。在代码文件里打出两个字母后，Litepad 会列出这个文件和其他打开的文件里用过的词；不需要的话，在「设置 › 编辑 › 补全」里关掉。Markdown 和纯文本里本来就不提示。

买了 Pro 但没有解锁

打开「设置 › 通用」，点恢复购买，并确认 App Store 登录的是购买时用的 Apple 账户。
