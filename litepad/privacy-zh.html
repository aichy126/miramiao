Litepad 隐私政策

最后更新：2026-10-10

本政策说明 miramiao（“我们”，www.miramiao.com）在你使用 Mac 文本与代码编辑器 Litepad（“本应用”）时如何处理你的信息。

一句话版本

我们不收集、不存储、也不会收到你的任何数据。本应用没有账号、没有统计分析、没有广告、没有追踪，也没有我们自己的服务器。你的文件和笔记只留在你的 Mac 上。

你的文件和文件夹

本应用只能打开你在「打开」面板里选择、拖进来，或在访达里用它打开的文件和文件夹。为了下次还能打开，它会在你的 Mac 上记一个书签。临时笔记保存在你 Mac 上的一个文件夹里，可以在设置里更改。任何内容都不会上传。

联网

本应用不会联系我们，只在你要求时联网：

  • Git —— 推送或拉取时，连接你自己配置的远程仓库（比如你自己的 Git 服务器）。该服务可能按其自身的政策记录请求。
  • Markdown 预览 —— Markdown 文件里引用了网上的图片时，预览会从存放该图片的网站加载它。

你 Mac 上的工具

代码追踪和格式化可以使用你 Mac 上已经装好的命令行工具（比如 Go 的语言服务器、格式化工具）。本应用通过一个小的辅助脚本在本机运行它们，这个脚本需要你在访达面板里允许一次。文字只交给你 Mac 上的这些工具，不会发给我们。

呼出快捷键

把 Litepad 叫到前台的全局快捷键是作为一个组合键注册给 macOS 的。本应用不会监听或记录你在其他应用里输入的内容，也不需要辅助功能权限。

购买

购买 Litepad Pro 时，交易由 Apple 通过 App Store 处理。我们看不到、也不保存你的付款信息。

数据的保留与删除

本应用产生的一切都只保存在你的 Mac 上，我们没有任何副本，因此没有需要我们保留或删除的数据。你的文件仍在你保存的位置。要删除本应用的设置和临时笔记，删除应用以及 ~/Library/Containers/com.miramiao.litepad 文件夹即可。

追踪

本应用不追踪你，也不会为了广告或统计与其他公司共享数据。

儿童

本应用不面向 13 岁以下儿童；由于我们不收集任何数据，也不会在知情的情况下收集儿童信息。

变更

我们可能会不时更新本政策，重大变更会体现在上方的「最后更新」日期中。
