Frequently asked

How do I bring Litepad forward from anywhere?

Press the summon shortcut (Control-Option-Space by default). The window comes to the desktop you are on, in front of other apps. Press it again to hide Litepad. You can change the shortcut in Settings › General.

Which keyboard shortcuts does it use?

Multiple cursors, line editing and selection follow the Sublime Text key bindings by default. Every command can be reassigned in Settings › Shortcuts, and the full list is in Help.

Go to Definition says it is searching by name

For Go, Litepad uses gopls when it is installed on your Mac (go install golang.org/x/tools/gopls@latest). The first time, Litepad asks you to allow a small helper script in a Finder panel so it can run the tool. Without gopls, definitions and references are found by name across the open folder.

Formatting doesn’t do anything

JavaScript, TypeScript, CSS, HTML, JSON, YAML and Markdown are formatted with the built-in formatter. Other languages use the tool installed on your Mac (for example gofmt or black); you can see what was found in Settings › Code.

I turned off the Dock icon. Where are the menus?

With no window open, Litepad lives in the menu bar only. As soon as a window is open, the Dock icon and the menus come back.

What’s in Litepad Pro?

The Git panel: compare uncommitted changes, a whole branch or everything since any commit, jump from change to change, commit and browse history; who last changed the current line, shown at its end; Go to Definition, Find References and hover info; formatting and format on save; all 12 themes and frosted glass. It also removes the free version’s limits of 5 tabs per window, the 10 latest scratch notes and 3 favorite projects. It is a one-time purchase, not a subscription.

My older scratch notes are gone

The free version keeps your 10 latest scratch notes. Older ones are moved to the Trash, never deleted outright, so you can get them back from there. Notes that are open stay where they are. Litepad Pro has no limit.

What is the gray text at the end of the line?

In a Git repository, the end of the line with the cursor shows who last changed that line, when, and the commit message. Lines that aren’t committed yet show “Uncommitted changes”. You can turn it off in Settings › Editing › Git.

Can I turn off the word suggestions while typing?

Yes. In code files, after two letters Litepad lists words already used in this file and the other open files. Turn it off in Settings › Editing › Completion. Markdown and plain text never show them.

I bought Pro but it isn’t unlocked

Open Settings › General and click Restore purchases, and make sure you are signed in to the App Store with the Apple Account used for the purchase.
