aiterm — Support

Last updated: 2026-10-12

aiterm is an iPhone and iPad client for an aiterm server running on your computer. It gives you that computer's terminal sessions, files and coding-agent conversation history. Sessions keep running on the computer when you disconnect.

Connect to your computer

  • Scan to connect: on the computer, open aiterm in a browser, go to Settings › 在手机上连接 (Connect on phone), and scan the code with the App (or the Camera app). The code works once and expires after two minutes.
  • Enter the address: type the server address, such as 192.168.1.20:9846 on your local network or https://shell.example.com from outside, then the server password.

Plain http is accepted only for local network addresses. Use https for anything reachable from the internet.

HTTPS with your own certificate

  • Self-signed certificate: the App shows the certificate's fingerprint. Compare it with the one shown on the computer, then trust it. From then on the App accepts only that certificate for this address and warns you if it changes.
  • Client certificate (mutual TLS): if your server asks for one, import the .p12 file and its password on the sign-in screen, then sign in again.

Troubleshooting

  • No response: check that the aiterm service is running, the address and port are right, and the device is on the same network for a local address.
  • Local addresses can't be reached at all: allow aiterm in Settings › Privacy & Security › Local Network.
  • Wrong password: run aiterm passwd in a terminal on the computer to set a new one. Every signed-in device will need to sign in again; running sessions are not affected.
  • Too many failed attempts: wait for the time shown, then try again.
  • The certificate has changed: if you did not change it, do not continue. If you did, check the new fingerprint against the computer before trusting it.

Contact

If you still need help, email info@miramiao.com with the App version and what happened. Do not send your password or certificate. See the Privacy Policy for how data is handled.
